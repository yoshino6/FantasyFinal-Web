This is a single empty panel frame asset, NOT a complete UI mockup. No title plaque, no tabs, no labels, no letters, no numbers, no logos, no watermark, no character, no human silhouette, no painted buttons, no interface text, no scene background. Genuine transparent alpha only outside the frame silhouette and rounded outer corners; the paper center is softly opaque. Crisp polished illustration, light warm fantasy anime palette, understated details that stay readable at phone UI size. Front-on flat view, no perspective, the frame occupies nearly the entire square canvas with only a narrow transparent outer margin.
